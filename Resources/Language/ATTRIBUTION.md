# Language data: sources and licences

AC Notch's correction engine is built from these public sources by `tools/build_language_data.py`.

| File | Built from | Licence |
| --- | --- | --- |
| `lexicon.txt` | [SCOWL](http://wordlist.aspell.net/) 2020.12.07 (Spell Checker Oriented Word Lists), sizes up to 70 (proper names up to 80), English/American/British/Canadian/Australian | SCOWL licence (below) |
| `unigrams.tsv` | [FrequencyWords](https://github.com/hermitdave/FrequencyWords) by Hermit Dave, `content/2018/en/en_50k.txt` (from OpenSubtitles 2018), filtered to SCOWL words; contraction counts estimated from Tatoeba | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). This file is an adaptation and is shared under the same licence. |
| `bigrams.tsv` | Word pairs counted in [Tatoeba](https://tatoeba.org) English sentences (90% of sentences; the rest are held out for testing) | [CC BY 2.0 FR](https://creativecommons.org/licenses/by/2.0/fr/) |

Benchmark data (`Benchmark/data`, not shipped in the app):

| File | Source | Licence |
| --- | --- | --- |
| `misspellings.tsv` | Wikipedia, [Lists of common misspellings](https://en.wikipedia.org/wiki/Wikipedia:Lists_of_common_misspellings) | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) |
| `synthetic.tsv`, `correct.tsv` | Held-out Tatoeba sentences; typos generated by the build script | [CC BY 2.0 FR](https://creativecommons.org/licenses/by/2.0/fr/) |
